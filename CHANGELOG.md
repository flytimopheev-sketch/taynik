# История изменений

Все значимые изменения проекта фиксируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версия — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.2.0] — 2026-10-21

### Исправлено

- 🔴 **Смена мастер-пароля больше не уничтожает данные.** Прежняя реализация
  меняла соль и verifier, но не перешифровывала записи: после смены пароля база
  оставалась зашифрованной старым ключом, и все пароли становились нечитаемыми.
  Теперь все поля записей и история паролей перешифровываются новым ключом в
  одной транзакции — при сбое изменение откатывается целиком.
- 🔴 **Исправлены тестовые векторы TOTP.** Два теста содержали неверные
  ожидаемые значения, из-за чего `cargo test` падал с версии 1.1.0. Реализация
  была корректна — расхождение подтверждено сверкой с эталонной реализацией
  HMAC и с таблицей RFC 6238. Добавлены все шесть векторов RFC 6238 (SHA-1 и
  SHA-256), а также векторы RFC 2202 и RFC 4231.
- 🟡 **Ошибка шифрования больше не превращается в пустой блоб.** В репозитории
  стоял `unwrap_or_default()`: при сбое шифрования в базу записывался пустой
  BLOB, и поле молча терялось. Теперь ошибка возвращается вызывающему и
  показывается пользователю.
- 🟡 **Резервная копия теперь согласованная.** Вместо копирования файла базы
  «как есть» (что могло поймать базу посреди записи) используется `VACUUM INTO`.
- 🟡 **Сохранение записи атомарно.** Запись в историю паролей и обновление
  записи выполняются в одной транзакции.
- 🟡 **Генератор паролей:** устранено смешение байтовой длины набора символов с
  номером символа — при не-ASCII наборе выбирался бы неверный символ.
- 🟡 **Тема оформления больше не течёт.** CSS-провайдеры, установленные для
  дисплея, удаляются при смене темы, а не накапливаются до конца работы
  приложения.
- 🟡 **Диалог TOTP больше не оставляет таймер.** Счётчик обновления кода
  завершается вместе с диалогом.
- 🟡 **Автоочистка буфера обмена не обнуляет новый пароль.** При повторном
  копировании предыдущий таймер отменяется.
- 🟡 **Ключ шифрования стал приватным.** Поле `CryptoKey` больше не публичное —
  его нельзя случайно вывести в лог или показать в диалоге.
- 🟡 **Мастер-пароль обнуляется в памяти** после вывода ключа.
- 🟡 **Ошибки базы больше не проглатываются** при обновлении списка и удалении
  записи — они показываются пользователю.
- 🟡 **Выделение записи в списке сразу открывает её** в форме. Раньше запись
  открывалась только по двойному щелчку — приходилось нажимать дважды на
  каждый элемент списка.
- 🟡 **Кнопки действий вынесены в отдельную нижнюю панель.** На невысоком окне
  кнопки «Сохранить» и «Удалить» уходили под нижний край прокручиваемой формы.
  Размер окна по умолчанию увеличен до 1100×780.
- 🟡 Убран мёртвый код (`src/app.rs`) и заглушка `#![allow(dead_code)]`,
  скрывавшая неиспользуемые участки кода.

### Добавлено

- 🔐 **Привязка шифротекста к имени поля (AAD).** Каждое зашифрованное поле
  теперь аутентифицируется вместе со своим именем: шифротекст нельзя
  переставить из одного столбца в другой. Базы, созданные ранее, читаются
  как обычно и автоматически мигрируют при первом открытии.
- 🧬 **Генератор парольных фраз (diceware).** 3–12 слов из встроенного словаря
  на 1024 слова (10 бит энтропии на слово), выбор разделителя, капитализация,
  добавление числа и символа в конце, расчёт энтропии.
- 🩺 **Аудит безопасности** (Вид → Аудит безопасности): слабые пароли,
  повторяющиеся пароли и пароли, не менявшиеся больше года. Каждая проблема
  открывается прямо в записи.
- 📦 **Зашифрованный экспорт и импорт** в формате `.taynik`: содержимое
  шифруется AES-256-GCM отдельным паролем, в файле нет открытого текста.
  Безопасная альтернатива CSV для переноса данных.
- 🔑 **Импорт TOTP из ссылки `otpauth://totp/…`** — извлекаются секрет,
  издатель, алгоритм, число цифр и период.
- 🔑 **Поддержка SHA-256 и 8 цифр в TOTP** (RFC 6238), параметры хранятся вместе
  с записью.
- ⭐ **Фильтр «только избранное»** и счётчик записей в панели поиска.
- 📋 Импорт CSV теперь понимает `true/false`, `yes/no`, `да/нет` в поле
  «избранное», а экспорт сохраняет параметры TOTP.

### Улучшено

- Добавлены модульные тесты для криптографии, репозитория, CSV, зашифрованного
  экспорта, аудита и генераторов (50 тестов).
- Тесты используют облегчённые параметры Argon2id — набор тестов стал заметно
  быстрее.
- В CI добавлены запуск `cargo fmt --check`, `cargo clippy` и `cargo test`:
  раньше CI собирал только RPM, из-за чего падающие тесты оставались незамеченными.

## [1.1.2] — 2026-09-14

- Автоввод: предпусковая диагностика — если вспомогательная утилита
  `xdotool` (X11) / `wtype` (Wayland) отсутствует, показывается понятное
  сообщение об ошибке вместо молчаливого бездействия.
- Автоввод: определение окружения по `XDG_SESSION_TYPE` (выбор xdotool/wtype)
  вместо проверки по `DISPLAY`/`WAYLAND_DISPLAY`, которая ошибочно выбирала
  xdotool в XWayland-сессиях Wayland.
- RPM: добавлена зависимость `xdotool` и мягкая (Recommends) `wtype`, чтобы
  автоввод работал «из коробки».
- Блокировка: при авто/ручной блокировке очищается список записей, чтобы
  после нажатия «Отмена» в диалоге мастер-пароля окно не выглядело
  отключенным с прежними записями.

## [1.1.1] — 2026-09-14

- Исправлена сборка RPM: устранены ошибки компиляции в `src/ui/main_window.rs`,
  из-за которых `%build` падал.
  - убрана дублирующая закрывающая скобка;
  - `DropDown::from_strings` получал `&Vec<String>` вместо `&[&str]`;
  - `gtk::show_uri` возвращает `()`, а код ожидал `Result`;
  - `copy_btn` в диалоге TOTP приводился к `Widget`, а не `Button`;
  - в экспорте CSV добавлен промежуточный `clone()` для `Rc<MainWindow>`.

## [1.1.0] — 2026-09-11

- Новое: настраиваемая последовательность автоввода (`{USERNAME}{TAB}{PASSWORD}`
  и произвольные токены) и диалог настроек.
- Новое: TOTP-коды по base32-секрету записи, история паролей с восстановлением.
- Новое: группы записей и цветовые метки, фильтр по группе.
- Новое: импорт/экспорт CSV, кнопки «Открыть URL» и «Скопировать логин».
- Новое: горячие клавиши копирования логина (`Ctrl+Shift+C`) и пароля
  (`Ctrl+Shift+P`).
- Скруглённые поля ввода во всех окнах; в диалоге «О программе» указан автор.

## [1.0.3] — 2026-09-11

- Убраны `RUSTFLAGS` с `-L` на системную glibc (из-за них бинарник требовал
  `GLIBC_2.39` даже при сборке через `cargo-zigbuild`).
- `cargo-zigbuild` теперь обязателен: при его отсутствии сборка падает, а не
  тихо откатывается на системный `cargo`.
- Добавлена проверка `%check`: сборка падает, если бинарник требует символы
  glibc новее 2.17.

## [1.0.2] — 2026-09-11

- RPM-сборка через `cargo-zigbuild` с целевой glibc 2.17: бинарник работает на
  РЕД ОС 7/8 и новее (раньше требовалась glibc 2.39 из ubuntu-24.04).

## [1.0.1] — 2026-09-11

- Сборка RPM напрямую в GitHub Actions (ubuntu-latest, без docker-контейнера).
- Исправлен `MimeType` в `taynik.desktop` (`application/x-taynik`).

## [1.0.0] — 2026-09-10

- Первый публичный выпуск: хранилище, генератор паролей, автоочистка буфера
  обмена, автоблокировка, автоввод, темы оформления.
